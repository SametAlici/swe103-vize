# SWE 103 — Yazılım Mühendisliğine Giriş · Vize Çalışma Sitesi

W1–W6 ders slaytlarına dayalı haftalık konu özetleri ve 5 çözümlü deneme vize sınavı (her biri 20 test + 2 klasik). Türkçe / English.

- Test sorularında şık seçilince doğru/yanlış ve açıklama hemen görünür; her soruda **Cevabı göster** düğmesi vardır.
- Klasik sorularda **Cevabı göster** ile örnek çözüm açılır.
- Statik site (HTML/CSS/JS), derleme gerektirmez; GitHub Pages ile yayınlanır.

Kişisel çalışma amaçlıdır; resmi ders materyali değildir.
